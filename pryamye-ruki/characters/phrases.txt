Баннер «Прямые руки» — реплики Бибы и Бобы

Биба (красный монстр-дедлайн) выкрикивает проблему в колючем красном пузыре, когда попадает по Бобе.
Боба (фиолетовый герой RBM) отвечает решением в скруглённом фиолетовом пузыре, когда попадает по Бибе.
Фраза и ответ берутся из одной пары; пара выбирается случайно и не повторяется подряд.

Проблема (Биба)  →  Решение (Боба)

 1. Непонятное ТЗ           →  Разобрали задачу за час
 2. Дедлайн вчера           →  Сдали в срок
 3. Нет презентации         →  Собрали презентацию
 4. Заявки теряются         →  Проанализировали заявки
 5. Нет текстов             →  Написали тексты
 6. Реклама сливает бюджет  →  Перенастроили рекламу
 7. Сайт не грузится        →  Починили сайт
 8. Пустые соцсети          →  Запустили соцсети
 9. Баннер к выставке       →  Нарисовали баннер
10. Нет отчётности          →  Настроили аналитику
11. Правки по кругу         →  Учли все правки
12. Каталог устарел         →  Обновили каталог
13. Конкуренты обходят      →  Нашли точки роста
14. Нет идей для акции      →  Придумали акцию

Отдельные надписи:
  Победа: «Все задачи решены!»
  Кнопка после победы: «Решим ваши задачи →»
  Подсказка: «← Кликайте для удара» (на телефоне «← Тапайте для удара»)
  Комбо: «КОМБО ×3!»
  Энергетик: «+45», после нокаута «+100»
